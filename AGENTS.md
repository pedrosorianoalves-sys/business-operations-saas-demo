# BusinessOps Demo — Codex Instructions

- Treat this repository as a public portfolio artifact. Never add real people, businesses, credentials, production URLs, or private operational data.
- All visible product copy and demonstration data must be English.
- Keep the application deployable to Vercel and the database reproducible from `supabase/migrations` plus `supabase/seed.sql`.
- Preserve anonymous per-visitor tenant isolation. No public shared mutable workspace.
- Write tests before production behavior changes and run the relevant red/green cycle.
- Keep domain validation and calculations independent from React and Supabase.
- Use semantic design tokens and existing shadcn components before custom UI primitives.
- Update `docs/PROJECT_CONTEXT.md` after meaningful milestones.
